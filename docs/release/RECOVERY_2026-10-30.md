## Technical mastery

A hash is a fingerprint of file bytes. Matching 64/64 hashes establishes faithful source reconstruction; it does not prove the software is correct. A Git commit is a named source snapshot. This branch is local and has not changed GitHub or Vercel.

Environment isolation is an application/cloud security boundary: both deployment targets of this staging Vercel project must connect only to the preview-test database. The factory checks the destination and credential role before constructing a database client. Public keys and server secrets have different privileges. Opaque modern keys do not encode their project identity, so account-side credential provenance still requires verification.

Authentication identifies the caller; authorization decides what that caller may do. The local tests exercise filmmaker, assigned-host and outsider behavior using synthetic database doubles. They do not prove hosted database policies, actual email delivery, or production behavior.

Commands: `npm test` executes the recovered behavior tests plus isolation tests; `npm run typecheck` checks TypeScript consistency; `npm run lint` checks source rules; `npm run build` compiles locally using inert database configuration. `npm audit --omit=dev` checks reported vulnerabilities in runtime dependencies only.
